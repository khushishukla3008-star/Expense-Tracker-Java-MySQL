# Expense Tracker – Java & MySQL

## About the Project
Expense Tracker is a desktop-based application developed using Java Swing and MySQL. It helps users record, organize and monitor their daily expenses.

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- NetBeans IDE
- XAMPP

## Features
- User login and registration
- Add and manage expenses
- Categorize expenses into Food, Travel, Shopping, Bills and Others
- Track expenses and budgets
- View expense summaries
- MySQL database connectivity using JDBC

## Database
Database: `expense_tracker`

The application uses MySQL to store user and expense information.

## How to Run
1. Clone this repository.
2. Open the project in NetBeans.
3. Start MySQL using XAMPP.
4. Create the `expense_tracker` database.
5. Import the provided SQL file.
6. Configure the database connection.
7. Run the project.
